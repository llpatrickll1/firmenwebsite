## GitHub Pages

Upload the complete folder to a repository and enable:

**Settings → Pages → Deploy from a branch → main → / (root)**

No build process is required.

## Design

The concept uses a restrained industrial visual system:
- dark technical surfaces
- acid-lime signal accent
- large Space Grotesk headlines
- engineering grid / instrument-inspired UI
- responsive layouts
- shared header/footer injected with JavaScript
- CSS product mockups, so the demo works without external image dependencies

## Source basis

The content architecture and technical facts were adapted from the public WEP website, including the three activity areas, MODCON/MODVIS/PR2/MPC, BOND, CVP21, Furtwangen location and CVP21 specifications.

Before publishing, replace placeholder visualizations with approved WEP product photography, verify all technical values, add the full legal/privacy texts and connect the contact workflow.
